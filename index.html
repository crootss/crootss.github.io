01 Kenapa

Tiga alasan memakai crootss.

Klik salah satu kartu, atau tekan → untuk menukik ke dalamnya.

±9 KB

CSS + JS minified, tanpa dependency. Tanpa Canvas, WebGL, atau WebAssembly.

HTML

Konten tetap teks di DOM: terindeks mesin pencari dan terbaca screen reader.

Tajam

Teks di-raster ulang setelah kamera berhenti. Zoom sedalam apa pun tetap jelas.

02 Pasang

Dua baris dari CDN.

Tanpa npm, tanpa build. Tempel di <head>, selesai.

Tanpa build! 
<link rel="stylesheet" href=
 "https://cdn.jsdelivr.net/gh/
 crootss/crootss@v0.4.0/crootss.min.css">

<script type="module" src=
 "https://cdn.jsdelivr.net/gh/
 crootss/crootss@v0.4.0/croot.min.js">
</script>

03 Tulis

Slide adalah HTML biasa.

Atur posisi dan rotasi lewat atribut. croot.js aktif otomatis.

<div class="croot-viewport" data-croot>
  <div class="croot-stage">
    <section class="croot-node"
      data-croot-step="1"
      data-croot-x="1500"
      data-croot-ry="-35">
      <h2>Halo</h2>
    </section>
  </div>
</div>

2.1 Coba

Buka di komputermu.

Browser tidak memuat ES module dari file://. Jalankan server lokal di folder slide, lalu buka http://localhost:8080/.

PowerShell bawaan Windows, tanpa instal

Buka PowerShell di folder slide, lalu jalankan:

irm https://crootss.if.co.id/serve.ps1 | iex

Browser terbuka otomatis. Tutup jendela untuk berhenti.

Python bawaan macOS dan Linux

Buka terminal di folder slide, lalu jalankan:

python3 -m http.server 8080

Di Windows, ketik python. Tekan Ctrl+C untuk berhenti.

3.1 Atribut

Semua lewat data-croot-*

stepUrutan: 1 → 2 → 2.1 → 2.10 → 3
x · y · zPosisi dalam piksel
rx · ry · rzRotasi dalam derajat
scaleSkala node; kamera menyesuaikan
targetKlik → kamera terbang ke selector lain

4.1 API

Kendalikan dari JavaScript.

ES module murni, plus event croot:enter, croot:leave, dan croot:overview.

import { croot } from
  '…/croot.min.js';

const deck = croot('#deck');
deck.next(); deck.prev();
deck.goto('api');
deck.overview();

deck.root.addEventListener(
  'croot:enter',
  e => console.log(e.target.id));

5.1 Gaya

Atur lewat CSS.

Kecepatan, perspektif, dan lebar slide cukup diubah dengan custom property. prefers-reduced-motion dihormati otomatis.

.croot-viewport {
  --croot-perspective: 1000px;
  --croot-speed: 1s;
  --croot-node-width: 960px;
  --croot-dim: .35;
}
