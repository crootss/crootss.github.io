Kenapa crootss?

Klik salah satu kotak, atau tekan → untuk menukik ke dalamnya.

±9 KB

CSS + JS minified, tanpa dependency. Tidak ada Canvas, WebGL, atau WebAssembly: hanya CSS 3D transforms bawaan browser.

HTML biasa

Konten tetap teks di DOM: bisa diindeks mesin pencari, dibaca screen reader, dan tampil sebagai dokumen saat JS mati.

Tetap tajam

Teks di-raster ulang setelah kamera berhenti, jadi zoom sedalam apa pun tidak membuatnya buram. Seperti kotak ini.

Pasang

Dua baris dari CDN. Tanpa npm, tanpa build.

<link rel="stylesheet" href=
 "https://cdn.jsdelivr.net/gh/crootss/crootss@v0.2.0/crootss.min.css">
<script type="module" src=
 "https://cdn.jsdelivr.net/gh/crootss/crootss@v0.2.0/croot.min.js">
</script>

Buka di komputermu

Browser tidak memuat ES module dari file://. Jalankan server lokal di folder slide, lalu buka http://localhost:8080/.

Windows PowerShell, tanpa instal apa pun

Buka PowerShell di folder slide, tempel seluruh blok ini, lalu tekan Enter. Tutup jendelanya untuk berhenti.

function start-server {
  # Content-Type wajib: browser menolak ES module tanpa MIME type JavaScript.
  $types = @{
    '.html'='text/html; charset=utf-8'; '.css'='text/css; charset=utf-8'
    '.js'='text/javascript; charset=utf-8'; '.mjs'='text/javascript; charset=utf-8'
    '.json'='application/json'; '.svg'='image/svg+xml'; '.ico'='image/x-icon'
    '.png'='image/png'; '.jpg'='image/jpeg'; '.jpeg'='image/jpeg'
    '.gif'='image/gif'; '.webp'='image/webp'; '.woff2'='font/woff2'
  }
  $listener = [System.Net.HttpListener]::new()
  $listener.Prefixes.Add("http://localhost:8080/")
  $listener.Start()
  Write-Host "Server jalan di http://localhost:8080/ (tutup jendela untuk berhenti)"
  while ($listener.IsListening) {
    $context = $listener.GetContext()
    $response = $context.Response
    $path = Join-Path $pwd.Path $context.Request.Url.LocalPath.TrimStart('/')
    if (!(Test-Path $path) -or (Test-Path $path -PathType Container)) {
      $path = Join-Path $path "index.html"
    }
    if (Test-Path $path -PathType Leaf) {
      $type = $types[[System.IO.Path]::GetExtension($path).ToLower()]
      if ($type) { $response.ContentType = $type }
      $bytes = [System.IO.File]::ReadAllBytes($path)
      $response.ContentLength64 = $bytes.Length
      $response.OutputStream.Write($bytes, 0, $bytes.Length)
    } else {
      $response.StatusCode = 404
    }
    $response.Close()
  }
}

macOS Terminal

Buka Terminal di folder slide (cd ke folder itu), lalu jalankan:

python3 -m http.server 8080

Jika macOS meminta instalasi Command Line Tools, setujui dulu, lalu jalankan ulang.

Linux Terminal

Python 3 sudah terpasang di hampir semua distro. Di folder slide, jalankan:

python3 -m http.server 8080

Tekan Ctrl+C untuk berhenti.

Atribut

data-croot-stepurutan: 1 → 2 → 2.1 → 2.10 → 3
data-croot-x / y / zposisi (px)
data-croot-rx / ry / rzrotasi (derajat)
data-croot-scaleskala; kamera menyesuaikan
data-croot-targetklik → kamera ke selector lain

Tiga cara bergerak

  • Linier: ← → Spasi PgUp/PgDn, atau swipe.
  • Klik langsung: klik node mana pun; urutan ikut tersinkron.
  • Overview: Esc menampilkan seluruh kanvas.

Setiap node punya alamat sendiri: #/navigasi.
